# Baharna · بحرنا

Live tides, sea conditions and a fishing outlook for UAE waters (Dubai default, plus Abu Dhabi, Al Rams, Fujairah, Khor Fakkan).

- Tide curve, next high/low and 7-day tide times (Open-Meteo Marine, sea level vs mean sea level)
- Wind and gusts in knots, wave height, sea surface temperature, sunrise/sunset (Open-Meteo)
- Boating sea-state and a simple fishing score (rule of thumb only)

Free data, no API keys. Deployed on Vercel. Forecasts are model-based and not official tide tables — always check official marine forecasts before going out.
